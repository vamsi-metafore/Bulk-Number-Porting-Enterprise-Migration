# Bulk-Number-Porting-Enterprise-Migration

**GitHub repository for the Bulk Number Porting for Enterprise Migration project. This repository contains the code and documentation necessary for implementing the feature that allows enterprise customers to port hundreds of numbers from another operator in scheduled waves.**

## Features

- ["Bulk number list upload"
- "Per-number batch status view"
- "Correction and resubmission of rejected numbers"
- "Whitelabel brand-aware portal access"]
